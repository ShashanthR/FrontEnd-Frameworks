Future Full-Stack Bootcamp Landing Page

A modern, responsive landing page built for an online full-stack development bootcamp using **Bootstrap 5**, HTML5, and custom CSS styling.

1. ✨ Features
- Hero Section: Full-viewport (vh-100) responsive introduction with custom call-to-action buttons and icons.
- Feature Cards ("How it Works"): Multi-column layout featuring dynamic card components with custom SVG illustrations (image1.svg, image2.svg, image3.svg).
- FAQ Accordion: Interactive Bootstrap accordion component for frequently asked questions.
- Custom Styling (app.css): Custom CSS variable overrides, custom spacing utility classes (mb-6 through mb-12), and bespoke color themes.
- Footer: Clean footer layout with a copyright marquee and custom branding.

2. 🛠️ Built With
- HTML5 - Markup structure
- Bootstrap 5 - Responsive grid system, components, and utility classes
- Bootstrap Icons - Scalable vector icons (bi-laptop)
- CSS3 - Custom variables and layout overrides
